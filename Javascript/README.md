# Weather Dashboard

## Project Overview
Weather Dashboard is a simple web application that allows users to search for any city and view the current weather details. It uses the Open-Meteo API to fetch live weather data and displays temperature, wind speed, and weather conditions with icons.

## Features
- Search weather by city name
- Displays current temperature
- Shows wind speed
- Displays weather condition
- Weather icons based on condition
- Error handling for invalid city names
- Search using button click or Enter key

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Open-Meteo API
